# Libra — Kotlin Multiplatform

Port of the SwiftUI app on `main` to Kotlin Multiplatform + Compose
Multiplatform. See [PLAN.md](PLAN.md) for the phased plan; the Swift original
is the reference for every ported file.

## Layout

- `core/` — KMP library, no Compose. Calculations, models, networking,
  persistence, providers, secrets, view models.
- `app/` — Compose Multiplatform UI. Produces the `LibraKit` framework that
  the iOS app links.
- `iosApp/` — thin Xcode shell, generated by XcodeGen from `project.yml`.

## Build

```sh
./gradlew :core:jvmTest                  # fast test loop
./gradlew :core:allTests                 # includes iOS simulator
./gradlew :app:assembleDebug             # Android APK
(cd iosApp && xcodegen && open Libra.xcodeproj)
```

## Toolchain

JDK 17, Android SDK (compile 36, min 26), Xcode 26+, XcodeGen.
