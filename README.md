# Libra — Kotlin Multiplatform

Port of the SwiftUI app on `main` to Kotlin Multiplatform + Compose
Multiplatform. See [PLAN.md](PLAN.md) for the phased plan; the Swift original
is the reference for every ported file.

## Layout

- `core/` — KMP library, no Compose. Calculations, models, networking,
  persistence, providers, secrets, view models.
- `app/` — Compose Multiplatform UI, as a KMP library. Produces the `LibraKit`
  framework that the iOS shell links.
- `androidApp/` — thin Android shell: `MainActivity`, manifest, theme.
- `iosApp/` — thin Xcode shell, generated by XcodeGen from `project.yml`.

## Build

```sh
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home

./gradlew :core:jvmTest                     # fast test loop
./gradlew :core:iosSimulatorArm64Test       # same tests, iOS
./gradlew :androidApp:assembleDebug         # Android APK
(cd iosApp && xcodegen && xcodebuild -scheme Libra \
   -destination 'generic/platform=iOS Simulator' build)
```

## Toolchain

JDK 21, Android SDK (compile 37, min 26), Xcode 27, XcodeGen.
Installed here via Homebrew; `local.properties` points at the SDK.

Everything large is relocatable: `GRADLE_USER_HOME`, `ANDROID_HOME`
(+ `sdk.dir`), `KONAN_DATA_DIR`.
