# docs

Finished plans, kept for reference. None of them is current. Code comments cite
them by name, and so do `RESUME.md` and `KNOWN_ISSUES.md`, which are working
notes kept out of the repository.

- [`PORT_PLAN.md`](PORT_PLAN.md): the Swift to Kotlin Multiplatform port, phases 0–9; `§N` citations mean this file.
- [`MAINTENANCE_PLAN.md`](MAINTENANCE_PLAN.md): the cleanup, open-issues and UI-parity pass that followed the port.
- [`LOOK_PLAN.md`](LOOK_PLAN.md): dark mode, the real palette and the fonts.
- [`UI_UX_PLAN.md`](UI_UX_PLAN.md): the math audit, charts, stats block, fades, UI refresh, cleanup and optimisation.
- [`refresh/`](refresh/README.md): light and dark screenshots on both platforms, from `UI_UX_PLAN.md` Stage 5.
